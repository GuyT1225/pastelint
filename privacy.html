Privacy Policy

How PasteLint handles browser-based text tools, local processing, analytics, hosting, and user privacy.

Privacy Policy

Last updated: 2026-11-18

PasteLint is designed as a privacy-first, browser-based text utility site. The core tools are intended to run in your browser without requiring a login, file upload, backend account, or AI API call.

Text you enter

Text entered into PasteLint tools is processed locally in your browser by client-side JavaScript. The site is designed so your pasted text is not uploaded to a PasteLint server.

No accounts

PasteLint does not require user accounts, usernames, passwords, or login credentials.

Browser storage and tool handoffs

PasteLint does not store your pasted text on a PasteLint server. When you choose to transfer text between tools, the site temporarily stores it in your browser's local storage. The receiving tool removes the transfer value after reading it. An interrupted transfer may leave text in browser storage until it is retrieved, overwritten or cleared. Theme and analytics preferences may also be stored locally. You can clear site data in your browser settings.

Hosting and third parties

PasteLint is hosted on GitHub Pages. Hosting providers may receive basic technical information such as IP address, browser type, device information, referring pages and request logs as part of normal web delivery. Some pages also request fonts from Google Fonts. External links and third-party services are governed by their own privacy practices.

Analytics

Website usage analytics are currently paused. The legacy analytics script has been disabled while a replacement is being tested. The site's analytics loader does not send usage events. Existing analytics preferences remain in browser storage. PasteLint will update this policy before enabling replacement analytics.

Speech preview

SSML Builder prepares text and markup in your browser. If you choose to play an audio preview, the browser's speech synthesis feature processes the preview text. Depending on your selected voice, browser and operating system, speech generation may use an external service. Use a local voice when available if you need offline speech processing.

Important reminder

PasteLint tools can help clean, rewrite, and format text, but you should review results before using them for factual, legal, medical, financial, professional, or sensitive communication.
